**Chrome Manifest V3** 기반 확장 프로그램으로, Photoshop 스타일의 눈금자(자) 바를 사용하여 웹페이지의 여러 구역을 수동으로 선택하고 각 구역을 독립적인 PNG 이미지로 저장할 수 있습니다. 눈금자 가이드, 마우스 선택 상자, CSS 클래스별 자동 선택 등 다양한 구역 분할 방법을 지원하며, 고해상도로 내보내기하여 타임스탬프 이름의 폴더에 자동으로 보관됩니다.

## 기능

### 구역 분할 (세 가지 방법은 병용 가능)

- **픽셀 눈금자 바**: 페이지 상단(X축)과 맨 왼쪽(Y축)의 눈금자. 눈금과 숫자가 있으며 HiDPI 화면에 대응
- **드래그로 가이드 생성**: 눈금자에서 마우스 왼쪽 버튼을 누른 채 드래그하면 세로/가로 가이드를 만들 수 있습니다
- **가이드 관리**: 위치를 드래그하여 수정 가능. 가이드를 클릭하면 삭제 버튼이 표시되며, 전체 가이드를 한 번에 모두 지울 수 있습니다
- **선택 상자**: 선택 상자 모드를 활성화한 후 페이지에서 마우스로 드래그하여 원하는 영역을 선택하면, 해당 상자가 스크린샷 영역이 됩니다
- **클래스 자동 선택**: CSS 클래스 이름을 입력하면 해당하는 모든 요소에 선택 상자가 자동으로 생성됩니다

### 스크린샷 및 내보내기

- **고해상도 내보내기**: 전체 페이지 캔버스와 저장된 PNG는 `문서 크기 × devicePixelRatio × EXPORT_SCALE`로 렌더링되며, 2배 확대하여 더 선명하게 출력됩니다
- **구역 크롭 PNG**: 한 번의 클릭으로 각 영역(가이드 그리드 셀 + 선택 상자)을 독립적인 PNG 이미지로 저장합니다
- **진행 모달**: 상세 진행률 표시줄, 현재/전체, 취소 작업, 완료 피드백(「다운로드 폴더 열기」 버튼 포함)
- **대용량 이미지 다운로드**: 오프스크린 문서를 사용하여 data URL을 세그먼트로 나누어 전송하고 Blob으로 변환하여 `chrome.downloads`의 data URL 2MB 길이 제한을 우회하므로, 초고해상도 스크린샷도 완전히 저장됩니다
- **시간 기준 자동 보관**: 각 배치는 현재 시간으로 이름이 지정된 독립 폴더(예: `2026年08月25日 14时30分55秒_500_A1B2`)에 저장되어 덮어쓰기와 디렉터리 오염을 방지합니다

### 사용 편의성

- **PNG 명명 규칙**: `번호_웹사이트명.png`(예: `1_example.png`). 웹사이트명은 URL에서 자동으로 추출됩니다
- **가이드 영속성**: 페이지를 새로 고치면 가이드가 자동으로 복원되며 URL별로 분리되어 페이지 간에 가이드가 공유되지 않습니다
- **단축키**: 기본적으로 `P` 키를 눌러 선택 상자 모드를 빠르게 전환하고(`ESC`로 종료), 설정에서 변경할 수 있습니다
- **설정 패널**: 선택 상자 단축키를 설정하고 저장할 수 있습니다
- **이중 진입 제어**: 브라우저 툴바 Popup + 페이지 내 플로팅 툴바

### 기타

- **작성자에게 커피 한 잔**: QR 코드로 작성자를 지원할 수 있는 기부 팝업이 내장되어 있습니다

## 로컬 로드 방법 (개발 모드)

1. Chrome을 열고 `chrome://extensions/`에 접속합니다
2. 오른쪽 위의 **개발자 모드**를 켭니다
3. **압축 해제된 확장 프로그램을 로드합니다**를 클릭합니다
4. 플러그인 루트 디렉터리(`manifest.json`이 포함된 폴더)를 선택합니다

## 사용 방법

1. **가이드 설정하기**
   - 페이지 **상단 눈금자**(X축)에 마우스를 이동하고 왼쪽 버튼을 누른 채 아래로 드래그하면 **가로 가이드**(Y 좌표를 나타내는 수평선)가 생성됩니다.
   - 페이지 **왼쪽 눈금자**(Y축)에 마우스를 이동하고 왼쪽 버튼을 누른 채 오른쪽으로 드래그하면 **세로 가이드**(X 좌표를 나타내는 수직선)가 생성됩니다.
   - 드래그하는 동안 현재 좌표(픽셀)가 실시간으로 표시됩니다.
   - 가이드는 **문서 좌표**로 배치되며(페이지 콘텐츠에 고정), 스크롤하면 페이지와 함께 이동합니다.
2. **가이드 조정하기**
   - 기존 가이드를 누른 채 드래그하면 위치를 변경할 수 있습니다.
   - 가이드를 클릭하면 빨간색 삭제 버튼이 표시되고, 클릭하면 해당 가이드를 삭제합니다.
3. **선택 상자 사용하기** (영역을 정확하게 선택하는 데 적합)
   - 툴바의 「선택 상자 활성화」 버튼을 클릭합니다(또는 기본 단축키 `P`를 누릅니다).
   - 활성화 후 페이지에서 왼쪽 버튼을 누른 채 직접 드래그하면 선택한 사각형이 스크린샷 영역이 됩니다. 여러 영역을 동시에 선택할 수 있습니다.
   - 각 선택 상자의 오른쪽 위에 삭제 버튼이 있습니다. `P`를 다시 누르거나 `ESC`를 누르면 선택 모드가 종료됩니다.
   - 단축키는 설정에서 변경하고 저장할 수 있습니다.
4. **클래스 자동 선택**
   - 툴바의 「클래스 자동 선택」 버튼을 클릭합니다.
   - 페이지 요소의 클래스 이름을 입력하고(앞의 `.`는 생략 가능) 확인합니다.
   - 해당 클래스와 일치하는 모든 보이는 요소에 선택 상자가 자동으로 생성됩니다.
5. **크롭 시작하기**
   - 플로팅 툴바 또는 Popup의 「PNG 크롭 시작」 버튼을 클릭합니다.
   - 눈금자 / 가이드 / 선택 상자 / 툴바가 숨겨지고 영역별로 스크린샷을 캡처하며 진행 모달이 표시됩니다.
   - 각 영역은 `번호_웹사이트명.png`로 이름이 지정되고 현재 시간으로 이름이 지정된 하위 폴더에 저장됩니다.
   - 완료 후 「저장된 폴더 열기」를 클릭하면 결과를 직접 확인할 수 있습니다.
6. **기타**
   - 「모든 가이드 지우기」로 모든 가이드와 선택 상자를 함께 제거합니다.
   - 「눈금자 숨기기/표시」로 눈금자 바 표시를 전환합니다.
   - 「설정」에서 선택 상자 단축키를 변경합니다.
   - 「작성자에게 커피 한 잔」으로 QR 코드를 스캔하여 작성자를 지원할 수 있습니다.

## 기술 설명

### 스크린샷 방식(스크롤 결합 + 영역별 크롭)

- **주요 방식**: **스크롤 결합** — 페이지가 아무리 길고/넓어도(가로·세로 스크롤바 포함) 먼저 페이지 전체를 창 크기로 그리드로 나눈 다음, 셀별로 스크롤하며 `chrome.tabs.captureVisibleTab`을 호출하여 실제 렌더링된 이미지를 캡처합니다.
  - 이전의 「전체 페이지 캔버스」 방식과 달리 현재 구현은 **거대한 전체 페이지 캔버스를 더 이상 생성하지 않습니다**(브라우저의 32,000픽셀 제한을 초과하여 빈 이미지가 나오는 것을 방지). 대신 **저장할 각 영역마다 독립적인 캔버스를 생성**하고, 스크롤하는 동안 창과 각 영역의 교집합을 해당 영역 캔버스에 직접 그려 메모리 사용량과 결합 실패 위험을 크게 줄입니다.
  - 보이는 부분과 보이지 않는(스크롤이 필요한) 부분 모두 완전히 저장됩니다.
  - 가이드 / 선택 상자가 유일한 분할 기준이며, 각 영역 = 가이드 그리드의 셀 + 사용자가 선택한 상자입니다.
  - html2canvas보다 충실도가 높은 실제 렌더링 스크린샷을 사용합니다.
- **캡처 빈도 제한**: `captureVisibleTab`을 스로틀링하고(두 호출 사이 최소 500ms), Chrome 할당량 오류 발생 시 자동으로 백오프 후 재시도하여 셀별 캡처 중 중단을 방지합니다.
- **HiDPI 확대**: `EXPORT_SCALE`(기본값 2)로 dpr에 추가로 확대하여 더 선명한 PNG를 출력합니다.
- **보조 방식**: `lib/html-to-image.js`(SVG `foreignObject`). 내부 스크롤 컨테이너와 같은 극단적인 상황의 대체 방안으로, 필요에 따라 확장할 수 있습니다.

### 대용량 이미지 다운로드(오프스크린 문서 + 세그먼트 전송)

- **문제점**: `chrome.downloads.download`가 data URL을 직접 받을 때 **2MB** 길이 제한이 있어 초고해상도 스크린샷이 실패하거나 `.txt`로 잘못 저장될 수 있습니다. 또한 MV3 Service Worker에서는 `URL.createObjectURL`을 사용할 수 없습니다.
- **방식**: 일반 DOM 환경에서 `data URL → Blob → blob URL` 변환을 수행하는 **오프스크린 문서**를 동적으로 생성합니다.
  - content script가 대용량 data URL을 4MB 단위의 세그먼트로 나누어 하나씩 전송하고(`DOWNLOAD_CHUNK`), 오프스크린 문서가 파일 이름별로 누적합니다.
  - 모든 세그먼트 전송 후 조립을 알림받아 순서대로 Blob으로 연결하고 blob URL을 생성합니다(`DOWNLOAD_ASSEMBLE`). 세그먼트가 누락되면 손상된 파일을 만들지 않고 오류가 발생합니다.
  - 최종 다운로드 작업은 Service Worker가 blob URL을 사용해 `chrome.downloads.download`로 수행합니다(오프스크린 문서에는 해당 권한이 없습니다).
- 각 이미지는 타임스탬프 이름의 하위 폴더에 저장되어 덮어쓰기와 디렉터리 오염을 방지합니다.

### 코드 아키텍처(높은 응집도, 낮은 결합도)

- 각 기능 모듈은 `content/modules/` 아래에 독립적으로 캡슐화되며 전역 `SSS` 네임스페이스에 마운트됩니다(ES 모듈이 아니라 manifest가 의존성 순서로 로드).
- 진입점 `index.js`는 **의존성 주입과 조립**만 담당하며 비즈니스 로직을 포함하지 않습니다.
- 모듈 간에는 **콜백 / 메시지**로 통신하여 직접적인 의존성을 피합니다.
- 모든 UI는 **Shadow DOM** 안에 있으며 호스트 페이지 스타일과 완전히 격리됩니다.
- 가이드 영속성은 URL별로 분리 저장되며(`{ sss_guides : { [url] : [] } }`), 읽기-수정-쓰기 경합을 피하기 위해 직렬 큐를 사용합니다.

### 주의 사항

- 전체 페이지 결합은 브라우저 창 캡처 API에 의존하며 페이지 전체를 셀별로 스크롤합니다. 페이지가 클수록 오래 걸립니다(셀당 다시 그리기가 완료될 때까지 약 250ms 대기).
- 페이지에 `position: fixed` 요소(예: 고정 내비게이션 바)가 있으면 결합 중에 그 요소가 모든 창 세그먼트에 나타납니다. 이는 전체 페이지 캡처의 고유한 한계입니다.
- 가이드 좌표는 문서(`window` 스크롤)를 기준으로 합니다. 페이지 본문이 내부 스크롤 컨테이너에 있다면 해당 컨테이너를 대상으로 조정해야 할 수 있습니다.
- 브라우저 보안 제한으로 일부 특수 페이지(예: `chrome://`, Chrome 웹 스토어)에는 스크립트를 주입할 수 없습니다.
- 페이지에 교차 출처 리소스가 있으면 캡처 API는 실제 렌더링된 이미지를 반환하므로 캔버스 교차 출처 오염의 영향을 받지 않습니다.

- [x] `manifest.json`이 JSON 검증을 통과하고 참조 파일이 모두 존재함
- [x] 명명 규칙 단위 검증(URL → 웹사이트명 → 파일 이름)
- [x] 구역 알고리즘 단위 검증(영역 수, 전체 면적 커버, 겹침 없음)
- [ ] 다양한 일반 페이지(긴 페이지, 스크롤 페이지, fixed 요소 포함 페이지)에서 실측
- [ ] 가이드 드래그, 수정, 삭제, 전체 지우기를 실측
- [ ] 선택 상자 드래그, 단축키 전환, 클래스 자동 선택을 실측
- [ ] 진행 모달, 취소, 초장 세그먼트 다운로드, 폴더 열기를 실측

> 팁: 확장 프로그램을 로드한 후 아무 웹페이지나 열어 위 흐름을 테스트해 보세요. 문제가 발생하면 페이지에서 마우스 오른쪽 클릭 → 「검사」 → Console에서 `[SSS]` 접두사 로그를 확인하세요.
