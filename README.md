# 网页分区截图插件 (Webpage Section Screenshot)

一个基于 **Chrome Manifest V3** 的插件，可以通过 Photoshop 风格的标尺栏手动框选网页的多个部分，并将每个部分保存为独立 PNG 图片。

## 功能特性

- **像素标尺栏**：页面顶部（X 轴）与最左侧（Y 轴）的标尺，带刻度与数字，适配高清屏
- **拖拽创建参考线**：按住鼠标左键从标尺拖动，可拖出纵向 / 横向参考线
- **参考线管理**：位置可拖动修改；点击参考线显示删除按钮；支持一键清空所有参考线
- **分区裁切 PNG**：一键开始裁切，将每个分区块保存为独立 PNG 图片
- **保存进度模态框**：详细进度条、当前/总数、取消操作、完成反馈
- **PNG 命名规则**：`序号_网页名称.png`（如 `1_example.png`）
- **参考线持久化**：刷新页面后自动恢复已设置的参考线
- **双入口控制**：浏览器工具栏 Popup + 页面内浮动工具条

## 本地加载方式（开发模式）

1. 打开 Chrome，访问 `chrome://extensions/`
2. 开启右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本插件根目录（包含 `manifest.json` 的文件夹）

## 使用说明

1. **设置参考线**
   - 将鼠标移动到页面**顶部标尺**（X 轴）上，按住左键向下拖动，即可创建一条**横向参考线**（水平横线，代表 Y 坐标）。
   - 将鼠标移动到页面**左侧标尺**（Y 轴）上，按住左键向右拖动，即可创建一条**纵向参考线**（垂直竖线，代表 X 坐标）。
   - 拖拽过程中会实时显示当前坐标（像素）。
   - 参考线按**文档坐标**定位（贴在页面内容上），页面滚动时参考线会随之移动。
2. **调整参考线**
   - 按住已创建参考线可拖动修改位置。
   - 单击参考线会显示红色的删除按钮，点击即可删除该条参考线。
3. **开始裁切**
   - 点击浮动工具条或 Popup 中的「开始裁切 PNG」按钮。
   - 插件会隐藏标尺/参考线，逐块截图并弹出进度模态框。
   - 每个分区块以 `序号_网页名称.png` 命名保存到默认下载目录。
4. **其它**
   - 「一键清空参考线」可移除全部参考线。
   - 「隐藏/显示标尺」可切换标尺栏是否显示。

## 技术说明

### 截图方案（整页滚动拼接 + 按参考线裁切）

- **主方案**：**滚动拼接整页截图**——无论页面多长 / 多宽（含横向与纵向滚动条），先按视口大小将整页划分为网格，逐格滚动并调用 `chrome.tabs.captureVisibleTab` 获取真实渲染画面，将全部片段按文档坐标拼接成一张完整的「整页 canvas」；随后以参考线为切分标准，从整页 canvas 中裁剪每个区块输出 PNG。
  - 可见与不可见（需滚动才能看到）的部分都会完整保存
  - 参考线是唯一切分标准，每个区块 = 参考线网格中的一个格子
  - 使用真实渲染截图，保真度高于 html2canvas
- **补充方案**：`lib/html-to-image.js`（SVG `foreignObject` 实现），可作为极端场景（如页面内部滚动容器）的备用，可按需扩展。

### 代码架构（高内聚低耦合）

- 各功能模块独立封装在 `content/modules/` 下，通过全局 `SSS` 命名空间挂载。
- 入口 `index.js` 仅负责**依赖注入与装配**，不包含业务实现。
- 模块间通过**回调 / 消息**通信，避免直接依赖。
- UI 全部置于 **Shadow DOM** 中，与宿主页面样式完全隔离。

### 注意事项

- 整页拼接依赖浏览器视口截图 API，会逐格滚动整个页面；页面越大会越耗时。
- 若页面包含 `position: fixed` 元素（如固定导航栏），拼接时该元素会在每个视口片段中出现，属于整页截图的固有局限。
- 参考线坐标基于文档（`window` 滚动），若页面主体在内部滚动容器中，可能需调整目标容器。
- 受浏览器安全限制，某些特殊页面（如 `chrome://`、应用商店）无法注入脚本。
- 页面包含跨域资源时，截图 API 返回的是真实渲染图，不受 canvas 跨域污染影响。
