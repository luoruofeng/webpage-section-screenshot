一个基于 **Chrome Manifest V3** 的插件，可以通过 Photoshop 风格的标尺栏手动框选网页的多个部分，并将每个部分保存为独立 PNG 图片。支持标尺参考线、鼠标选区框、按 Class 自动选区等多种划分方式，高清导出并自动归入按时间命名的文件夹。

## 功能特性

### 区域划分（三种方式可组合使用）

- **像素标尺栏**：页面顶部（X 轴）与最左侧（Y 轴）的标尺，带刻度与数字，适配高清屏
- **拖拽创建参考线**：按住鼠标左键从标尺拖动，可拖出纵向 / 横向参考线
- **参考线管理**：位置可拖动修改；点击参考线显示删除按钮；支持一键清空所有参考线
- **选区框**：开启选区框模式后，直接在页面上用鼠标拖拽框选任意区域，框内即作为一个截图区块
- **自动选区 (Class)**：输入 CSS Class 名，插件自动为页面中所有匹配元素创建选区框

### 截图与导出

- **高清导出**：整页 canvas 与保存的 PNG 均按 `文档尺寸 × devicePixelRatio × EXPORT_SCALE` 渲染，支持 2 倍放大，导出更清晰
- **分区裁切 PNG**：一键开始裁切，将每个区域（参考线网格格 + 选区框）保存为独立 PNG 图片
- **保存进度模态框**：详细进度条、当前/总数、取消操作、完成反馈（完成可一键打开下载文件夹）
- **超大图下载**：通过离屏文档（Offscreen Document）将 data URL 分段传输并转成 Blob 下载，突破 `chrome.downloads` 对 data URL 的 2MB 长度限制，超分辨率截图也能完整保存
- **按时间自动归档**：每次截图保存到以当前时间命名的独立文件夹（如 `2026年08月25日 14时30分55秒_500_A1B2`），避免同名覆盖与目录污染

### 易用性

- **PNG 命名规则**：`序号_网页名称.png`（如 `1_example.png`），网页名称从 URL 自动解析
- **参考线持久化**：刷新页面后自动恢复已设置的参考线，且按 URL 隔离，不同页面互不串用
- **快捷键**：默认按 `P` 键快速开启 / 关闭选区框（`ESC` 退出），快捷键可在设置中自定义
- **设置面板**：支持配置选区框快捷键并持久化保存
- **双入口控制**：浏览器工具栏 Popup + 页面内浮动工具条

### 其它

- **请作者喝咖啡**：内置赞赏弹窗，可扫码支持作者

## 本地加载方式（开发模式）

1. 打开 Chrome，访问 `chrome://extensions/`
2. 开启右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本插件根目录（包含 `manifest.json` 的文件夹）

## 使用说明

1. **设置参考线**
   - 将鼠标移动到页面**顶部标尺**（X 轴）上，按住左键向下拖动，即可创建一条**横向参考线**（水平横线，代表 Y 坐标）。
   - 将鼠标移动到页面**左侧标尺**（Y 轴）上，按住左键向右拖动，即可创建一条**纵向参考线**（垂直竖线，代表 X 坐标）。
   - 拖拽过程中会实时显示当前坐标（像素）。
   - 参考线按**文档坐标**定位（贴在页面内容上），页面滚动时参考线会随之移动。
2. **调整参考线**
   - 按住已创建参考线可拖动修改位置。
   - 单击参考线会显示红色的删除按钮，点击即可删除该条参考线。
3. **使用选区框**（适合精确框选某块区域）
   - 点击工具条上的「开启选区框」按钮（或按默认快捷键 `P`）。
   - 开启后直接在页面上按住左键拖拽，框选出的矩形区域即作为一个截图区块，可同时框选多个。
   - 每个选区框右上角有删除按钮；再次按 `P` 或按 `ESC` 可退出选区框模式。
   - 快捷键可在「设置」中修改并保存。
4. **自动选区 (Class)**
   - 点击工具条上的「自动选区 (Class)」按钮。
   - 输入页面元素的 Class 名（可省略开头的 `.`），点击确认。
   - 插件会为页面中所有可见且匹配该 Class 的元素自动创建选区框。
5. **开始裁切**
   - 点击浮动工具条或 Popup 中的「开始裁切 PNG」按钮。
   - 插件会隐藏标尺 / 参考线 / 选区框 / 工具条，逐块截图并弹出进度模态框。
   - 每个区域以 `序号_网页名称.png` 命名，保存到以当前时间命名的子文件夹中。
   - 全部完成后可点击「打开保存的文件夹」直接查看结果。
6. **其它**
   - 「一键清空参考线」可同时移除全部参考线与选区框。
   - 「隐藏/显示标尺」可切换标尺栏是否显示。
   - 「设置」可修改选区框快捷键。
   - 「请作者喝咖啡」可扫码支持作者。

## 技术说明

### 截图方案（滚动拼接 + 按区域裁切）

- **主方案**：**滚动拼接**——无论页面多长 / 多宽（含横向与纵向滚动条），先按视口大小将整页划分为网格，逐格滚动并调用 `chrome.tabs.captureVisibleTab` 获取真实渲染画面。
  - 与早期「整页 canvas」方案不同，当前实现**不再创建一张巨大的整页 canvas**（避免超过浏览器 32k 像素限制导致空白），而是**为每个要保存的区块创建独立的 canvas**，在滚动过程中将视口与区块的交集部分直接绘制进各区块 canvas，显著降低内存占用与拼接失败风险。
  - 可见与不可见（需滚动才能看到）的部分都会完整保存。
  - 参考线 / 选区框是唯一切分标准，每个区块 = 参考线网格中的一个格子 + 用户框选的选区。
  - 使用真实渲染截图，保真度高于 html2canvas。
- **截图频率控制**：对 `captureVisibleTab` 做节流（两次调用至少间隔 500ms），并在触发 Chrome 配额错误时自动退避重试，避免整页逐格截图时因调用过快而中断。
- **高清放大**：通过 `EXPORT_SCALE`（默认 2）在 dpr 基础上进一步放大导出，让 PNG 更清晰。
- **补充方案**：`lib/html-to-image.js`（SVG `foreignObject` 实现），可作为极端场景（如页面内部滚动容器）的备用，可按需扩展。

### 超大图下载方案（离屏文档 + 分段传输）

- **问题**：`chrome.downloads.download` 直接接收 data URL 受 **2MB 长度限制**，超分辨率截图会下载失败或被错误存成 `.txt`；而 MV3 的 Service Worker 中不可用 `URL.createObjectURL`。
- **方案**：动态创建 **Offscreen Document（离屏文档）**，在常规 DOM 环境中完成 `data URL → Blob → blob URL` 的转换。
  - Content Script 将超大 data URL 按 4MB 切成多个 chunk 分段发送（`DOWNLOAD_CHUNK`），离屏文档按文件名累积；
  - 全部发送完成后通知离屏文档按序拼接组装为 Blob 并生成 blob URL（`DOWNLOAD_ASSEMBLE`），缺失分片会报错而非产出损坏文件；
  - 最终下载动作由 Service Worker 使用 blob URL 调用 `chrome.downloads.download` 完成（离屏文档无该权限）。
- 每张图片保存在按时间命名的独立子文件夹中，避免同名覆盖与目录污染。

### 代码架构（高内聚低耦合）

- 各功能模块独立封装在 `content/modules/` 下，通过全局 `SSS` 命名空间挂载（由 manifest 按依赖顺序加载，非 ES Module）。
- 入口 `index.js` 仅负责**依赖注入与装配**，不包含业务实现。
- 模块间通过**回调 / 消息**通信，避免直接依赖。
- UI 全部置于 **Shadow DOM** 中，与宿主页面样式完全隔离。
- 参考线持久化按 URL 隔离存储（`{ sss_guides: { [url]: [] } }`），并使用串行队列避免读-改-写竞态。

### 注意事项

- 整页拼接依赖浏览器视口截图 API，会逐格滚动整个页面；页面越大会越耗时（每格约等待 250ms 确保重绘完成）。
- 若页面包含 `position: fixed` 元素（如固定导航栏），拼接时该元素会在每个视口片段中出现，属于整页截图的固有局限。
- 参考线坐标基于文档（`window` 滚动），若页面主体在内部滚动容器中，可能需调整目标容器。
- 受浏览器安全限制，某些特殊页面（如 `chrome://`、应用商店）无法注入脚本。
- 页面包含跨域资源时，截图 API 返回的是真实渲染图，不受 canvas 跨域污染影响。
